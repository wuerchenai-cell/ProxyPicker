ProxyPicker 怎么发给朋友
======================================================================

结论：不用只挑一个网站，按人数分两档就够。


一、就给两三个人 → 微信 / QQ 直接发文件（首选）
--------------------------------------------------
把 ProxyPicker-v1.3.4-share.zip（约 154 KB；本地包名是 ProxyPicker-分享版.zip）拖进聊天窗口发过去，就完了。

  好处：不用注册、不用登录、不会过期、不经过任何网盘审核。
  缺点：只适合一个个发，不能给一大群人。

约 154 KB 很小，微信发文件毫无压力。


二、要一个链接、发给一群人 → 蓝奏云
--------------------------------------------------
网址：https://www.lanzou.com

注册一个号，上传那个 zip，它会给你一条链接（可设提取码）。
朋友点开链接直接下载，**不用注册、不用登录**，速度也不错。

  免费额度：单文件 100 MB 以内（我们只有 0.1 MB）、空间不限、
            链接长期有效、不限制下载速度。
  缺点：网页广告多；超过 100 MB 要会员。

这是国内分享小工具最常用的做法，专门就是干这个的。


三、备用镜像 → 123 云盘
--------------------------------------------------
网址：https://www.123pan.com

同样支持免登录下载，单文件限制比蓝奏宽松得多，速度不限。

  什么时候用它：蓝奏抽风、链接被限速、或者你想同时给两个链接
                让朋友"哪个能下点哪个"。


四、懂技术的朋友 → GitHub
--------------------------
https://github.com/wuerchenai-cell/ProxyPicker/releases/latest

程序里的「检查更新」就是查这个地址。
注意：GitHub 上最新 Release 是 v1.3.4，和这个分享包是同一版。
程序里的「检查更新」只在 GitHub 上的版本号比本机大时才提醒，不会把人引去下载旧包；
它只提示 + 打开下载页，绝不自动下载或替换自己。
国内有时打不开或很慢，所以它只当备份，不当主入口。


不要用这几个
--------------------------------------------------
  百度网盘        朋友要装客户端 + 登录 + 被限速，为了 154 KB 不值
  夸克 / 阿里云盘  下载要登录，多一道坎
  Gitee           传附件要实名认证，配置麻烦，收益不如蓝奏


三条必须注意的（踩了会白忙）
--------------------------------------------------

1. 传 zip，别传裸 exe。
   网盘对 .exe 的审核比压缩包严，有些会直接拦下来。我们本来就有 zip。

2. 文件名保持中性。
   就叫「ProxyPicker-v1.3.4-share.zip」（本地包叫「ProxyPicker-分享版.zip」），别改成"翻墙/机场/加速器/科学上网"之类。
   更不要发到论坛、贴吧、公众号、公开群里。
   这类工具在国内平台审核很严，容易删文件、封号。
   只私下发给认识的人，链接给谁你自己控制。

3. 一定要提前跟朋友说 SmartScreen 那一步。
   这个 exe 没买数字签名（一年几千块），第一次双击八成会弹
   「Windows 已保护你的电脑」。不提前说，人家会以为中了病毒直接删掉。
   正确操作：点「更多信息」→「仍要运行」。
   如果连"仍要运行"都不给点：右键 exe → 属性 → 最下面勾「解除锁定」→ 确定。

   详细说明在压缩包里的「说明-先看这个.txt」中「两种模式」那一段，已经写好了。


----------------------------------------------------------------------
下面这段可以直接复制发给朋友（把 <链接> 换成你的链接）
----------------------------------------------------------------------

给你个小工具，能单独控制哪些软件走梯子、哪些直连。
平时挂梯子，微信、游戏、网盘想直连又不想切全局的，用这个正好。

下载：<链接>
解开压缩包，双击 ProxyPicker.exe，不用安装、不写注册表。

用之前先确认两件事：
1. 你电脑上得在跑 Clash Verge（或 Clash Nyanpasu / Mihomo Party），
   并且开了 TUN 模式。这工具自己不带梯子，它只负责分配谁走。
2. 第一次打开会弹「Windows 已保护你的电脑」——
   点「更多信息」→「仍要运行」。它用的是自签名证书，Windows 不认识发布者，
   不是病毒（商业代码签名证书还没买）。

第一次默认是「代理白名单」：只有你勾上的软件走代理，其余一律直连
（跟没开代理一样）。想沿用订阅原来的分流，去帮助面板切「订阅兼容」。
想收起来点标题栏的「—」，会缩到右下角托盘，规则照常生效。
（点「×」不是收起：会先把内核配置还原再退出；只有「—」是收进托盘。也可以右键托盘图标 →「退出 ProxyPicker（还原配置）」。）

用腻了想撤：点窗口「×」退出，或用托盘「还原上次保存前的配置」——这会删掉接管名单，
后台看守不再补回。只去 Clash Verge 点「更新订阅」只是暂时冲掉规则，程序还在跑就会补回来。
删干净要清四处：exe、%LOCALAPPDATA%\ProxyPicker\、开机启动项（开过才有）、
客户端的 pp_rules 目录（很老的版本迁移才用到，新版本不写它）。

有问题点右上角「?」→「复制诊断信息」，把复制的内容发我。
