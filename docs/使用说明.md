ProxyPicker v3.0.0 使用说明（企业级 WPF 工作台）
==================================================

官方仓库 / 下载最新版 / 反馈问题：https://github.com/wuerchenai-cell/ProxyPicker
单文件绿色便携 exe，约 1,217 KB（1,246,232 字节），无需安装、无需额外下载运行库（Windows 10/11 自带 .NET Framework 4.8），不修改您的机场订阅源文件，100% 自动兼容并无损继承 v2.x 配置与固定 IP 保险箱。

一、核心定位与架构亮点
----------------------
ProxyPicker 是一款面向 Clash / mihomo 系代理客户端（Clash Verge Rev / FlClash / Sparkle / Clash Nyanpasu / Mihomo Party / 裸 mihomo）的企业级按进程分流工作台：
1. 严格五层单向架构 + KernelCoordinator 串行优先事务队列（P0 退出还原 > P1 用户操作 > P2 联动同步 > P3 看守补回 > P4 后台优选）+ ConfigRevision 乐观锁 CAS，彻底杜绝并发竞态与旧测速覆盖新配置；
2. 内置 PowerResumeGuard 系统休眠唤醒与墙钟跳变防风暴宽限期（唤醒后 12 秒静默，不再乱弹假超时或误退）；
3. 原生 WPF MVVM 企业级界面，支持深色 / 浅色 / 跟随 Windows 系统主题即时热切换，高 DPI（100%–150%+）全矢量清晰渲染。

二、六大一级工作区指南
----------------------
1. 【应用分流】
   - 顶部左右双独立仪表盘：左卡并排显示「主代理」与「独立固定 IP」实时延迟与前置跳板状态；右卡以三色实时矢量走势曲线（蓝=主代理、紫=固定IP、灰=本地直连）展示每秒吞吐速率与活跃连接数；
   - 软件表格支持 [ 直连 | 主代理 | 固定IP ] 三态胶囊一键直切，改动后点右下「保存并热推生效」，仅定向断开变动软件的旧连接，不中断其他正常下载或长连接；
   - 顶部工具栏随时切换「白名单模式（未分配一律直连，默认推荐）」与「订阅兼容模式（未分配沿用原订阅）」，支持手选任意 `.exe` 添加绿色版/脚本软件。

2. 【节点与多固定IP】
   - 左栏「主代理节点池」：并发全部测速、一键切换主出口、勾选「备选」加入故障转移池并开启超时自动切换；
   - 右栏「多固定 IP 通道池」：默认通道完全兼容 v2.x `PP-STATIC-OUT`/`PP-STATIC-HOP`，现支持「+ 新建通道」配置多条独立住宅/静态出口（SOCKS5/HTTP）；支持一行粘贴智能解析（`socks5://user:pass@ip:port` 或 `ip:port:user:pass`）；支持每 10 分钟零干扰旁路 3 次稳态复核优选前置跳板；默认自动注入 UDP/QUIC 防穿透 `REJECT` 规则防真实 IP 泄露。

3. 【实时连接监视】
   - 白盒实时展示当前所有活跃连接的软件进程、目标地址:端口、TCP/UDP 协议、实际出站通道、完整出站链与累计流量；
   - 自动高亮「错路旧连接」，支持按软件/通道筛选、一键断开单条连接或「一键断开全部错路连接」。

4. 【链路与DNS体检】
   - 顶部「DNS 防泄漏与通道安全体检（只读建议）」：实时检查内核 TUN / 内置 DNS / 固定 IP UDP 防护状态，给出不越权修改客户端的 DoH / DNS 建议；
   - 支持零干扰隔离侧车单节点或全量节点风控评估（真实落地地区、家宽/机房属性、双源风控评分、Google / Gemini / OpenAI / Claude 四门放行实测）及一键复制全脱敏诊断报告。

5. 【四向联动与预设】
   - 真正完整的四向对称软件联动：
     ① 开 A 随开我：勾选跟随目标软件默认自动激活后台静默守望（保存即生效），平时正常打开目标软件即自动拉起 ProxyPicker；
     ② 开我随开 B：打开 ProxyPicker 自动按「代理客户端优先 → 内核在线 + 规则强门禁确认 → 业务软件」顺序拉起伴随软件；
     ③ 关 A 随关我：目标软件彻底退出经精确完整路径 + 多进程可见窗口防抖确认后，自动还原内核并退出；
     ④ 关我同关 B：主动退出 ProxyPicker 时，永远先经 P0 队列干净还原内核配置，再按「业务软件 → 代理客户端」顺序发送优雅关闭消息（不粗暴强杀丢数据）。
   - 同时支持「一键创建桌面原生图标联动快捷方式」与「命名场景预设（一键整套切换分流名单、模式与默认固定 IP）」。

6. 【系统设置与审计】
   - 外观主题热切换（深色 / 浅色 / 跟随系统）、当前用户免管理员开机自启、IPv6 防泄漏开关；
   - 跨机配置迁移：使用 PBKDF2-SHA256 + AES-256-CBC + HMAC-SHA256 认证加密导出/导入全部规则、预设、联动与固定 IP 凭据；
   - 只读 GitHub Release 版本检查（绝不自动下载覆盖）、一键彻底还原内核配置，以及右栏可按分类筛选与搜索的全链路脱敏审计日志时间线。

三、迷你浮窗与系统托盘
----------------------
- 点击标题栏右上「迷你浮窗」可切换至紧凑置顶网速/双延迟小挂件，双击或点击「展开主界面」返回完整工作台；
- 点标题栏右上「✕」将隐藏到系统托盘继续后台看守与 10 分钟稳速巡检；如需彻底退出，请在托盘图标右键选择「退出（自动还原内核并同步联动关闭）」。

四、只读命令行诊断开关
----------------------
  ProxyPicker.exe --version <输出文件>      输出版本号
  ProxyPicker.exe --diag <输出文件>         输出全脱敏诊断报告（含 DNS 体检）
  ProxyPicker.exe --delay <输出文件>        实测主代理与全部启用固定 IP 通道延迟
  ProxyPicker.exe --scan <输出文件>         输出当前扫描到的运行进程与软件列表
  ProxyPicker.exe --checkupdate <输出文件>  只读查询官方最新 Release 版本
