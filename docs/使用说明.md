ProxyPicker 使用说明
====================

下载最新版 / 反馈问题：https://github.com/wuerchenai-cell/ProxyPicker

这是什么
--------
一个托盘小工具：只让「你勾选的软件」走代理，其余软件怎么走由你选的模式决定。
改完点保存，只重连这次改到的软件，其他连接不会断，也不用重启浏览器。

分流模式（帮助面板底部那个按钮，随时能切）
  · 只改勾的（新机器默认）：勾的走代理，其余完全按订阅原规则走。
    装完上网习惯一点不变，只是在规则最前面插了几行。给别人用选这个。
  · 完全接管（本机一直在用）：勾的走代理，其余一律直连。
    订阅里那几百条分流规则会被一条兜底规则挡在后面，暂时不起作用。
    这是刻意的设计（只让需要外网的走代理，最省流量），但第一次用容易懵 ——
    发现某个软件上不了网，先回来看看它有没有勾上。
切完必须点一次「保存并生效」才会真正改到内核。


怎么用
------
1. 双击 exe，右下角出现图标，面板自动弹出。
2. 点一行 = 开/关。开 = 走代理，关 = 直连。
3. 点右下角「保存并生效」。底部会告诉这次重连了几个软件、清掉几条旧连接。
4. 标题栏右边「—」= 收进托盘；「×」也是收进托盘，都不退出程序，
   代理规则照常生效。真要退出，在托盘图标上右键 → 退出。


四个标签
--------
常用    高频软件 + 已勾选的软件
已选    核对当前代理名单
运行中  此刻正在跑的软件
全部    所有已安装软件。以后新装的软件，下次打开会自动出现，不用手工维护


排序
----
· 按住任意一行上下拖动，就能改顺序。
· 点标签右侧的按钮，可以切回「智能」（按勾选习惯自动排）、「手动」或「按名称」。
· 排序和习惯存在 settings.json 里，下次打开还在。


右键一行
--------
改为直连 / 只代理这一个 / 打开文件位置 / 复制进程名 / 在列表中隐藏


实时网速
--------
摘要卡右侧是两条通道的实时速率：
  代理 = 勾选软件走代理的流量
  直连 = 其余软件直接连的流量
下面那条折线是最近一分多钟的走势。数据来自本机内核的连接表。


换节点（重要）
--------------
摘要卡第三行那个浅蓝胶囊，写的是「勾选的软件现在实际走哪个节点」——
它追的是真实链路末端，不是 Clash 界面上的全局选择。

换节点就在 Clash Verge 里换（切「🚀 节点选择」组）。换完 10 秒内：
  · 胶囊自动变成新节点名
  · 弹出「出口已切到 xxx」的提示
不用点刷新，也不用重启软件。

想让勾选的软件单独钉死一个节点（不跟主组走）：
在 Clash Verge 的 PP-FIXED 组里直接选具体节点即可。
选「🚀 节点选择」是跟随，选「♻️ 自动选择」是跟着测速漂移。


关于 IPv6
---------
本机已关闭 mihomo 的 IPv6。原因：TUN 的 IPv6 地址是内网段，Windows 不会拿它
当访问公网的源地址，于是 IPv6 流量会从物理网卡直接溜出去 —— 换节点对它完全无效，
而且会把你的真实 IP 暴露给支持 IPv6 的网站。

关掉后所有网站都走 IPv4，全部纳入代理。
副作用：纯 IPv6-only 的站点访问不了（这种站极少）。
要恢复：在 Clash Verge 里把 merge 扩展的 `ipv6: false` 去掉，或改成 true。


版本与更新
----------
点标题栏的「?」，面板右上角会显示当前版本，例如 v1.0.0。

接上 GitHub 仓库以后，那里会多一句「检查更新」，点一下才去查；查到新版就写成
「v1.0.0 → v1.1.0 去下载」，点了打开浏览器，自己下载替换 —— 程序不会自动下载、
不会改自己。原因很实在：这个 exe 没有数字签名，「自己下载自己覆盖自己」这个行为
最容易被 Defender / SmartScreen 当成恶意软件。

自动检查每天最多一次，连不上（没开代理）就安静算了，不弹窗不打扰。
不想要这个功能：把 settings.json 里的 "updateCheck" 改成 false。


换电脑
------
整个 exe 拷过去就能用，不需要安装、不写注册表。程序会自动识别这些客户端：
  Clash Verge Rev / Clash Verge / Clash Nyanpasu / Mihomo Party / FlClash /
  Clash for Windows / 裸 mihomo

想把手感一起带走：把 settings.json 放在 exe 旁边（绿色模式），
排序、使用次数、隐藏项都会跟着走。


分享给别人
----------
直接发 `分享包\ProxyPicker-分享版.zip` 就行，里面是 exe + 一份「说明-先看这个.txt」，
那份说明是按「完全不懂的人」写的，把前提条件、会被 Windows 拦、怎么撤销都写进去了。

发之前你要知道三件事：
1. 对方电脑上必须本来就有 Clash Verge 之类的客户端、并且开着 TUN。
   这工具不带代理，它只是分配谁走代理。
2. 对方那边没有 PP-FIXED 这个组，程序会自动挑「🚀 节点选择」这类组，
   已经用一份「删掉 PP-FIXED」的配置试跑过，选组是正确的。
3. 对方第一次打开走「只改勾的」模式，不会动他订阅里的规则 ——
   这是他和我这边最大的不同，也是分享版不会把人网搞坏的原因。
   判断依据是有没有 settings.json：没有就是新机器，走保守模式。
4. 真机只在 Clash Verge Rev 上验证过；其它客户端是按目录结构写的，没实测。


怎么撤掉（回到原本的分流）
--------------------------
方法一（推荐）：Clash Verge →「订阅」→ 右键在用的配置 →「更新」或重新应用。
                客户端重新生成配置时会把工具插的规则冲掉，恢复原样。
方法二：删掉配置里 rules: 段首那几条 PROCESS-NAME 和紧跟的 MATCH,DIRECT。
彻底删干净：exe、%LOCALAPPDATA%\ProxyPicker\、
            %APPDATA%\io.github.clash-verge-rev.clash-verge-rev\pp_rules\


规则被客户端冲掉了会怎样
------------------------
换订阅、重启 Verge、改设置都会重新生成配置，把插进去的规则冲掉。

现在它自己每 30 秒核对一次（收进托盘也不停）：发现「名单非空但规则没了」
就自己补回去，屏幕上闪一句「规则被冲掉了，已自动补回」。只少几个的那种
半丢状态只记账、不动手，免得把你自己在客户端里的调整抹掉。
连续 3 次补不回来会停手并提示手动保存，不会无限重试。

它做过的每一次补回 / 失败都记在 %LOCALAPPDATA%\ProxyPicker\actions.log。
实测：637 条规则、IPv6 开着（界面看不出来的那种故障）→ 托盘里放着不动
→ 33 秒后自己补成 647 条并把 IPv6 关掉。


出问题怎么办
------------
点标题栏的「?」→「复制诊断信息」，里面写着识别到的客户端、配置路径、
内核版本、规则条数、名单是否生效，最后附最近 10 条「它自己做过什么」。
把这些贴出来就能定位问题。

命令行也能用（前四个只读，不改任何配置）：
  ProxyPicker.exe --diag 诊断.txt
  ProxyPicker.exe --audit 对账.txt      名单 vs 内核，逐条列出差异
  ProxyPicker.exe --selftest 自检.txt
  ProxyPicker.exe --api 输出.txt /proxies      直接问内核要原始数据
  ProxyPicker.exe --raw 输出.txt GET /rules    连响应头一起打出来，排查用
  ProxyPicker.exe --version 版本.txt           版本号 + 版本比较自检
  ProxyPicker.exe --checkupdate 更新.txt        查一次 GitHub 上的最新版本
