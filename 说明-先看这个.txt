ProxyPicker · 看这一页就够了
======================================================================

它是什么
--------
一个绿色小工具（单个 exe，约 960 KB，带图标），用来决定「哪些软件走代理、哪些直连」。

比如你平时挂梯子，但微信、QQ、游戏也想直连（省流量、不卡），
以前只能全局切来切去。装上它就能给每个软件单独一个开关。


必须先满足的前提（不满足就用不了）
----------------------------------
1. 电脑上已经在用 Clash Verge（或 Clash Nyanpasu / Mihomo Party / FlClash）。
   这个工具自己不带代理，它只是「分配谁走代理」，梯子还得你自己有。

2. 强烈建议开着「TUN 模式」（Clash Verge 里那个虚拟网卡开关）。
   为什么：这个工具的原理是「让内核按进程名给流量分配出口」，
   内核得先看得见这条流量才管得着。TUN 在网卡层接住全部流量，谁都跑不掉。
   不开 TUN 只能用系统代理，那只对「愿意读系统代理」的软件有效
   （浏览器、IDM 这类），微信、QQ、游戏、Antigravity 这类程序根本不读，
   它们的流量根本不进内核 —— 勾了也不会生效。

   程序会自己检测：勾了但内核看不见的软件，右边会标成橙色「没走代理」，
   不会假装成功。看到橙标就开 TUN，或者去那个软件自己的设置里填 127.0.0.1:7897。

3. Windows 10 1903 以上，或 Windows 11。老系统要装 .NET Framework 4.8。


怎么用
------
1. 双击 ProxyPicker.exe。
2. 列表里每个软件右边有一个开关：开 = 走代理，关 = 直连。
3. 改完点右下角「保存并生效」。会弹一句「已生效」，不用重启浏览器。

4. 想先把它收起来：点标题栏右边的「—」。窗口会缩到右下角托盘里，
   代理规则照常生效，再点一下托盘图标就回来了。

   要退出：点标题栏的「×」，或者右键托盘图标 →「退出 ProxyPicker（还原配置）」。
   退出时它会把内核里的规则撤掉，并把 find-process-mode 恢复成原值，
   不会在内核里留下改动。如果你是从 v1.0/v1.1 升级的，旧版还可能往
   客户端 profile 里写过扩展；先跑一次 `--cleanlegacy 清理.txt --yes`
   清掉（会备份），才算真正回到没装过的状态。

顶部那个「出口 日本-B」的小标签，显示的是勾选的软件现在实际走哪个节点，
你在 Clash Verge 里换节点，它十秒内会自己变。


⚠ 先说清楚它会改什么（默认只让点名的软件出网）
------------------------------------------------
第一次运行，默认是「代理白名单」模式。保存之后：

    勾上的软件      → 走代理
    其余所有软件    → 一律直连（跟没开代理一样）

也就是说，装完之后除了你勾的那几个，其他软件不走代理、也不按订阅规则分流；
访问国外网站会打不开是正常的。想保持原来的上网习惯，请在帮助面板底部
切到「订阅兼容」，再点一次「保存并生效」。

如果你想沿用订阅原来的分流规则：
打开帮助面板（标题栏的「?」），底部有个「模式」按钮，点一下切成
「订阅兼容」，再点一次「保存并生效」。那时候：

    勾上的软件      → 走代理
    其余所有软件    → 按订阅自己的规则走（原来能上的还能上）

订阅里那几百条自动分流规则会被一条兜底规则挡在后面，暂时不起作用。

    适合：你就是想让这台电脑只有点名的软件能出国，其他一律本地直连。
    不适合：你平时习惯全局挂梯子 —— 切之前先想一下，切完可能觉得网坏了。

两种模式随时能来回切，切完记得点一次「保存并生效」。


第一次运行被 Windows 拦了
-------------------------
会弹「Windows 已保护你的电脑」。因为这个 exe 没有花钱买数字签名，
不是病毒。点「更多信息」→「仍要运行」就行。

如果被 SmartScreen 直接拦下不给运行，右键 exe →「属性」→
最下面勾「解除锁定」→ 确定，再双击。


用腻了怎么撤（重要）
--------------------
这个工具只改 Clash 客户端的规则，不改系统设置，随时能退回原样：

方法一（推荐）：打开 Clash Verge → 「订阅」→ 右键你在用的那个配置
                → 点「更新」或「重新应用」。客户端会重新生成配置，
                  工具插进去的规则就被冲掉了，恢复你原本的分流。

方法二：在 ProxyPicker 里把所有开关都关掉，点保存。
        「代理白名单」模式下这就是「全部直连」——注意不是恢复原样，是全部不走代理；
        「订阅兼容」模式下等于什么都没做，跟你没装过一样。

想彻底删干净，三个地方：
    ProxyPicker.exe 本身              直接删
    %LOCALAPPDATA%\ProxyPicker\       设置、名单、日志、备份
    （从 v1.0/v1.1 升级过才需要）    先跑 --cleanlegacy 清理.txt --yes，
                                      再删客户端 profiles 里遗留的 ProxyPicker 扩展


有个「自己看着」的小功能
------------------------
Clash Verge 换订阅、重启、改设置时会重新生成配置文件，
工具插进去的规则就会被冲掉。以前只有你打开面板它才发现，
现在它自己每 30 秒去问一遍内核：我加的规则还在不在？

- 规则没了 → 自己补回去，屏幕上闪一句「规则被冲掉了，已自动补回」
- 只是少了几个（可能你自己在客户端里删的）→ 只在后台记一笔，不动手
- 连续 3 次补不回来 → 停手，提示你手动点一次「保存并生效」

收进托盘（点「—」）之后它照样在看，所以不用为了这个把窗口开着。

IPv6 归 Clash Verge 自己管，本程序默认一个字都不碰（新版客户端会把外部写的 ipv6
当成越权并弹提示）。如果你在意 IPv6 泄漏，最稳的做法是在客户端设置里关掉 IPv6；
也可以在帮助面板里打开「IPv6 防泄漏」，关掉开关即恢复不管的状态。
代价：关掉 IPv6 后，只支持 IPv6 的网站会连不上（现在几乎没有这种网站）。

它做过的每一次「自动补回 / 放弃 / 失败」都记在
    %LOCALAPPDATA%\ProxyPicker\actions.log
里，一行一次，带时间和原因。觉得它乱动过，翻这个文件就能对账。


支持哪些客户端（实测过的很有限，见下）
--------------------------------------
代码里认这些：Clash Verge Rev / Clash Verge / Clash Nyanpasu /
              Mihomo Party / FlClash / Clash for Windows / 裸 mihomo

但是：**只在 Clash Verge Rev 上真机跑过**。其他客户端是按它们的
      目录结构写的，没在真机上验证，可能会认不出来。
      内核必须要是 mihomo（clash.meta）系，老的 Clash Premium 不行。

认不出来的时候，面板顶部会写「未检测到客户端」，不会乱改你的配置。


出问题想反馈
------------
点标题栏的「?」→「复制诊断信息」，把复制到的东西发给我。
里面写着你用的是哪个客户端、配置在哪、内核版本、规则条数、
名单有没有生效，还有最近 10 条「它自己做过什么」。有这些基本就能定位。
复制前会自动打码：用户名、路径、节点名、订阅链接都不会带出去。


这一版是 v1.3.2（2026-11-10）
------------------------------
· 中途切换客户端不容易再连错：程序缓存的内核通道（管道名 / 端口 / 密钥）
  现在绑定在「当前选中的那份订阅配置」上；你开着软件时换了客户端或订阅，
  本次保存确认的配置路径会一路带到密钥读取、控制口读取和推送，不再出现
  「连的是 A 的通道、推的是 B 的配置」那种保存看着成功、其实推错地方的错配。
  注意：识别客户端的结果有 5 秒缓存，切换后立刻点保存（或用 --raw / --diag
  这类调试命令）仍可能按旧通道走。**切换客户端或订阅后等几秒再保存最稳妥。**
· 修好「还原了又被自动接管」的竞态：托盘还原与后台自动补回同时发生时，
  补回前会在保存锁内再核一次接管意图；如果你已经撤销（还原），补回不会再
  把接管状态重新推回去。
· 旧版备份（没记录来源的）不再整份推回——那是换客户端前的旧订阅，直接推回去
  会把你已经更新过的订阅整个换掉。现在改为按当前订阅重建一份干净配置
  （只拿走本工具的规则块，订阅原规则逐字保留）。备份创建失败会中止本次推送，
  不再谎报「保存成功」。
· 自检 154 项全过（通用性 114 + 控制接口安全 31 + 流量对账 9）。
· 接管意图核对与模式无关：订阅兼容模式下删掉名单文件即撤销接管，自动补回也会停手
  （原来兼容模式豁免核对，会重新推回接管规则）；识别为「意图已撤销」后不计失败、
  不弹「请点保存」，记 SKIP 日志。
· 一次保存只 Detect 一遍配置：绑定判定、密钥读取、控制口读取、推送，以及推完之后的
  回读校验，都锁定同一份配置路径，不会「按 A 生成、按 B 绑定」。退出还原、托盘还原
  和后台看守对账也按同一份路径走；只有 --raw / --diag 这类单独敲的调试命令仍会
  自己重新识别一次客户端（见上面的 5 秒缓存提示）。

上一版是 v1.3.1（2026-11-10）
------------------------------
· 打开软件就自动检查更新，不用记得去点：托盘会弹系统通知告诉你有新版本，
  面板收着、开机自启后台运行也一样会查。点通知打开面板，点版本号去下载页。
  每天最多联网一次，没连上 4 小时后重试；上次查到过新版的话，即使当天
  不联网，下次启动也会再提醒一次。程序仍然不会自动下载、不会替换自己。
· 修好「分流异常」的两种假警报：程序自己放行的辅助进程（例如 codex.exe）
  不再被报成「没勾却走代理」；规则生效前就建立的浏览器长连接也不再被算成
  「勾了却走直连」。诊断里会写明排除了几条旧连接。
· 自检 133 项全过（比上一版多 9 项回归）。

把之前评审里剩下的建议一次性补齐了：

下面这些是上一轮积累的修复（v1.2.5 未单独发布，已全部包含在本版）：
· 修好了默认 Clash Verge Rev 下「订阅一更新，规则就补不回来」：程序原来把
  mihomo 的默认档 strict 误当成「没开进程识别」，看守每 30 秒一看就放弃。
  其实 strict 下按软件分流的规则完全正常，只有 off 才是真关闭。
· 修好了「开着本软件 ChatGPT 登不上、关掉就好」：ChatGPT 桌面版的登录窗口
  跑在系统共享的 WebView2 里，它没在勾选名单里，就被「未勾的一律直连」送了出去。
  现在只要你勾了软件，登录窗口会一起放行；不想要这个例外，切到「订阅兼容」
  模式，或把 settings.json 里的 loginWindowProxy 改成 false。
· 清空名单（全部直连）现在也会被看守维护：订阅重载后自动补回直连兜底，
  退出时也会把这条兜底撤掉，不再留一个「全部直连」在内核里。
· 摘要卡的「分流异常 N 个」可以点开看完整清单了，异常多时不再只显示两个名字
  加一个「等」；每条都写清预期、实测、原因和下一步，还能直接复制。
· 保存后回读校验万一失败，界面名单也会跟着内核同步，不会把刚取消勾选的软件
  又自动补回来。

上两版（v1.2.4 / v1.2.3）修的是空名单兜底位置与「别误伤、别留残留」：
· 你自己写在订阅规则最前面、策略叫 PP-FIXED 的进程规则，不会再被当成
  工具的旧规则删掉。现在只删带完整 `# PP-BEGIN / # PP-END` 标记的块。
· 退出还原：不再只看第一条规则；只要内核里任意位置还有本工具的规则就还原。
  读内核失败时按「有」处理，不再因为读不到就跳过还原。find-process-mode
  也会恢复成接管前的值，不再永久留下 always。
· 目录规则边界收紧：`C:\Program Files\bin`、`C:\Users\Public` 这类公共容器
  不再生成整树规则；装在 `Public\App` 里的软件仍然只覆盖它自己的 App 目录。
· 勾 Electron 软件不会再顺手写一条全局 `node.exe` 规则；node / python / java
  这类共用运行时只由目录规则覆盖，不按裸名全局代理。
· 名单里有解析不了的行时，保存会直接停下并告诉你是第几行，不会把那条
  悄悄改成直连。
· 摘要卡「分流异常 N 个」后面会直接跟软件名；帮助面板第一行列出原因和
  下一步，完整列表在「复制诊断信息」里。
· `--scan` 也脱敏了（以前只有 --diag/--api/--raw 脱敏），并把访问域名打码。
· 从 v1.0 / v1.1 升级的用户，可以用 `--cleanlegacy` 清掉旧版写进
  Clash Verge profile 的扩展（先备份，只认 ProxyPicker 标记）。
· 窗口拖到不同 DPI 的显示器时会重建字体和尺寸，不再模糊/错位。

更早的 v1.2.1 已包含：按安装目录整树覆盖 helper、任务栏图标、
固定刻度曲线、托盘「还原上次保存前的配置」。
